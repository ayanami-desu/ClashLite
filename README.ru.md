# ClashLite

[English](README.md) | [简体中文](README.zh-Hans.md) | [繁體中文](README.zh-Hant.md) | **Русский**

Минималистичный клиент [mihomo](https://github.com/MetaCubeX/mihomo) для строки меню macOS.

## Зачем это нужно

Ядро mihomo умеет само размещать веб-панель (`external-ui`), а панели вроде [metacubexd](https://github.com/MetaCubeX/metacubexd) уже отлично справляются с прокси, соединениями, правилами и логами. Тем не менее большинство клиентов всё равно строят поверх собственную панель: функции дублируются, а размер и сложность растут. А ядро в это время недоумевает: «У меня же есть своя панель?»

Идея ClashLite проста: **делать только то, что не умеет ядро, а остальное оставить ядру и его панели.**

- «Клиентские» задачи — управление процессом ядра, профилями, обновлением подписок, переопределениями и авторизацией TUN — берёт на себя ClashLite
- «Панельные» задачи — просмотр соединений, логов, правил и проверка скорости — в один клик открываются в панели, размещённой ядром
- Самые частые повседневные действия (смена режима, переключение прокси, включение режима TUN) находятся в строке меню, так что открывать панель не нужно

Ни главного окна, ни значка в Dock — только значок в строке меню.

## Возможности

- **Панель, размещённая ядром**: открывается в один клик с автоматически подставленными адресом и секретом, бэкенд не нужно указывать вручную. По умолчанию используется metacubexd; другую панель можно задать через `external-ui-url` в профиле. Панель можно обновить из меню
- **Управление профилями**: поддерживаются ссылки на подписки и локальные YAML-файлы. Подписки могут обновляться автоматически (по умолчанию с интервалом `profile-update-interval` из подписки). Локальные профили можно редактировать прямо в приложении, профили подписок — просматривать
- **Проверка профилей**: при импорте, редактировании и обновлении профиля, а также при сохранении переопределения сначала выполняется полная проверка ядром (`mihomo -t`), поэтому некорректный профиль никогда не применяется
- **Переопределения**: «переопределения профиля» (действуют на один профиль) и «глобальное переопределение» (действует на все профили), объединяются глубоким слиянием YAML
- **Быстрые действия в строке меню**: смена режима прокси (Правила / Глобальный / Напрямую), переключение прокси в группах (с задержкой), снятие фиксации, закрытие всех соединений, перезапуск ядра
- **Режим TUN**: авторизация нужна только один раз; при включении DNS автоматически переводится в режим fake-ip, а DNS-сервер локальной сети заменяется публичным, чтобы запросы попадали в туннель
- **Синхронизация с панелью**: смена режима, переключение прокси и другие действия в панели синхронизируются обратно в строку меню и сохраняются после перезапуска ядра
- **Запуск при входе в систему**
- **Многоязычность**: английский, упрощённый китайский, традиционный китайский и русский, в соответствии с языком системы

## Системные требования

- macOS 15 или новее
- Mac на Apple silicon или Intel (универсальный бинарный файл)

## Установка

1. Скачайте последнюю версию на странице [Releases](../../releases) и перетащите ClashLite в «Программы». В каждом выпуске есть следующие DMG:

   | Файл | Описание |
   | --- | --- |
   | `ClashLite-x.y.z-mihomo-vA.B.C-arm64.dmg` | Со встроенным ядром mihomo (последняя стабильная версия на момент сборки), для Apple silicon. Рекомендуется |
   | `ClashLite-x.y.z-mihomo-vA.B.C-amd64.dmg` | Со встроенным ядром mihomo, для Intel |
   | `ClashLite-x.y.z.dmg` | Без ядра, его нужно добавить самостоятельно |

2. Приложение не нотаризовано, поэтому перед первым запуском снимите атрибут карантина:

   ```sh
   xattr -cr /Applications/ClashLite.app
   ```

   Либо, если первый запуск был заблокирован, нажмите «Все равно открыть» в «Системных настройках → Конфиденциальность и безопасность».

### Ядро

Версии со встроенным ядром при первом запуске копируют его в папку ядра — больше ничего делать не нужно. Уже существующее ядро в папке не перезаписывается, поэтому обновление ClashLite не заменит ваше собственное ядро. Чтобы перейти на ядро из новой версии, удалите `mihomo` из папки ядра и снова откройте ClashLite.

Если вы используете версию без ядра или хотите выбрать версию ядра сами:

1. Скачайте ядро для своей архитектуры со страницы [mihomo Releases](https://github.com/MetaCubeX/mihomo/releases) (`mihomo-darwin-arm64-*.gz` для Apple silicon, `mihomo-darwin-amd64-*.gz` для Intel) и распакуйте его
2. В строке меню нажмите «Ещё → Открыть папку ядра», поместите туда распакованный файл и **переименуйте его в `mihomo`**
3. Сделайте его исполняемым и снимите атрибут карантина:

   ```sh
   cd ~/Library/Application\ Support/com.oxi.ClashLite/Core
   chmod +x mihomo
   xattr -d com.apple.quarantine mihomo
   ```

4. В строке меню появится версия ядра; после добавления профиля ядро запустится автоматически

Чтобы позже обновить ядро, просто замените этот файл и нажмите «Ещё → Перезапустить ядро». Если включён режим TUN, после замены потребуется повторная авторизация.

## Использование

### Переопределения

Переопределение — это YAML-словарь, который накладывается на профиль в следующем порядке:

```
Профиль → Переопределение профиля → Глобальное переопределение → Настройки ClashLite (режим, TUN, контроллер и т. д.)
```

Правила слияния:

- Словари объединяются рекурсивно по ключам, остальные значения заменяются
- Для списков `+key` вставляет элементы перед исходным списком, а `key+` — добавляет после него

Например, чтобы собственные правила имели приоритет над правилами подписки:

```yaml
+rules:
  - DOMAIN-SUFFIX,example.com,DIRECT
```

### Режим TUN

Для создания виртуального сетевого интерфейса нужны права root. При первом включении ClashLite покажет системный диалог авторизации администратора, сделает владельцем файла ядра root и установит бит setuid — после этого авторизация больше не потребуется. При замене файла ядра эти права теряются, и запрос появится снова.

macOS не может перехватывать DNS-запросы, отправленные на DNS-сервер локальной сети, через интерфейс TUN. Когда режим TUN включён и текущий сетевой сервис использует DNS-сервер локальной сети, loopback или link-local, ClashLite удаляет такие серверы, чтобы запросы попадали в туннель; существующие публичные DNS-серверы сохраняются, а если их нет, используются 223.5.5.5 и 119.29.29.29. Исходные настройки восстанавливаются при выключении TUN, остановке ядра или выходе из ClashLite. Это поведение управляется пунктом меню «Перехватывать системный DNS» и включено по умолчанию.

Приложения, которые отправляют DNS-запросы напрямую на жёстко заданный сервер локальной сети, не затрагиваются. Пока TUN включён, split DNS и внутренние домены, которые разрешаются только через DNS локальной сети, могут перестать работать; в этом случае отключите «Перехватывать системный DNS».

### Расположение файлов

Все данные хранятся в `~/Library/Application Support/com.oxi.ClashLite/`:

| Путь | Описание |
| --- | --- |
| `Core/mihomo` | Исполняемый файл ядра |
| `Home/` | Рабочая папка ядра: Geo-данные, наборы правил, панель и т. д. |
| `Home/mihomo.log` | Лог ядра, очищается при каждом запуске |
| `Profiles/` | Профили; имя файла — это название профиля |
| `Overrides/` | Переопределения профилей |
| `Override.yaml` | Глобальное переопределение |

### Безопасность

- Контроллер слушает только `127.0.0.1:9097`, секрет генерируется случайно при первом запуске
- Путь к панели также генерируется случайно
- Итоговая конфигурация передаётся ядру через переменную окружения, поэтому секрет и данные прокси не попадают в аргументы процесса

## Сборка из исходного кода

Требуется Xcode 26 или новее (в проекте используются Swift 6.2 и значок Icon Composer).

```sh
git clone <адрес репозитория>
cd ClashLite
open ClashLite.xcodeproj
```

Зависимость ([Yams](https://github.com/jpsim/Yams)) загружается автоматически через Swift Package Manager.

### Локализация

Строки интерфейса хранятся в каталоге строк `ClashLite/Localizable.xcstrings`, исходный язык — английский. Чтобы добавить или изменить перевод, отредактируйте его в Xcode.

### Выпуск

Отправка тега, начинающегося с `v`, запускает GitHub Actions, которые собирают DMG и создают Release. Версии со встроенным ядром при сборке загружают последнюю стабильную версию mihomo и собираются отдельно для arm64 и amd64:

```sh
git tag v1.0.0
git push origin v1.0.0
```

Workflow можно также запустить вручную на странице Actions — результаты сборки загружаются как артефакты.
